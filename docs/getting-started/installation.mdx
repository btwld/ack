---
title: Installing Ack
---

Ack is a pure-Dart package with no required build step. Add the core library — and, optionally, the code generator for immutable models.

## Add to your project

Add Ack to your project using the Dart CLI:

```bash
# For Dart projects
dart pub add ack

# For Flutter projects
flutter pub add ack
```

The unversioned commands select the latest stable release. To select the
2.0.0-alpha.1 prerelease, add it to your `pubspec.yaml`:

```yaml
dependencies:
  ack: ^2.0.0-alpha.1
```

## Dart 3.14 prerelease setup

This Ack 2.0 development branch is pinned to **Flutter 3.50.0-0.1.pre**,
which bundles **Dart 3.14.0-315.1.beta**. The stable 3.50.0 / 3.14.0 releases
are not available yet. Use `sdk: '>=3.14.0-315.1.beta <4.0.0'` for this
prerelease; the stable target is `sdk: '>=3.14.0 <4.0.0'` once released.
Primary constructors are enabled by default. Augmentations remain experimental
and must be enabled in consumer projects:

```yaml title="analysis_options.yaml"
analyzer:
  enable-experiment:
    - augmentations
```

```bash
dart run build_runner build --enable-experiment=augmentations
dart --enable-experiment=augmentations test
# For a Dart application:
dart --enable-experiment=augmentations run bin/main.dart
# For a Flutter application:
flutter run --enable-experiment=augmentations
flutter test --enable-experiment=augmentations
```

`@Schemable()` classes use ordinary `part '<file>.g.dart';` directives.
Generated `augment final class` / `augment sealed class` declarations add
members to the source class; they do not change its primary constructor.
The pinned beta formatter cannot preserve these declarations. Do not run
`dart format` over generated `.g.dart` parts; Ack formats its generated output.
In this repository, `dart run melos run format` selects authored sources only.

## Optional code generator

To generate models from Ack schemas or Ack schemas from hand-written models,
add `ack` and the generator package:

```bash
dart pub add ack
dart pub add --dev ack_generator build_runner
```

Or add them to your `pubspec.yaml`:

```yaml
dependencies:
  ack: ^2.0.0-alpha.1

dev_dependencies:
  ack_generator: ^2.0.0-alpha.1
  build_runner: ^2.16.2
```

The generator works in both directions with one annotation, `@Schemable()`,
and one constraint namespace, `@Validate.*`, both exported from
`package:ack/ack.dart`. `@Schemable()` on a top-level schema generates an
immutable model. `@Schemable()` on a hand-written class generates a
`_<className>Schema` codec, a public `<ClassName>Schema` facade, and JSON
helpers. There is no `@AckSchema()` annotation; `AckSchema` is the runtime
schema type.

```dart
import 'package:ack/ack.dart';

part 'user.g.dart';

@Schemable()
final userSchema = Ack.object({
  'name': Ack.string(),
  'email': Ack.string().email(),
});

@Schemable()
final class const Account({
  @Validate.minLength(2) required final String name,
});
```

Run the generator:

```bash
dart run build_runner build --enable-experiment=augmentations
```

See [Model Code Generation](../core-concepts/typesafe-schemas.mdx) for working
tutorials, supported shapes, and guidance on choosing a direction.
