---
title: Installing Ack
---

Ack is a pure-Dart package with no required build step. Add the core library — and, optionally, the code generator for immutable models.

## Add to your project

Add Ack to your project using the Dart CLI:

```bash
# For Dart projects
dart pub add ack

# For Flutter projects
flutter pub add ack
```

The unversioned commands select the latest stable release. To select the
1.7.0-beta.4 prerelease, add it to your `pubspec.yaml`:

```yaml
dependencies:
  ack: ^1.7.0-beta.4
```

## Optional code generator

To generate models from Ack schemas or Ack schemas from hand-written models,
add `ack` and the generator package:

```bash
dart pub add ack
dart pub add --dev ack_generator build_runner
```

Or add them to your `pubspec.yaml`:

```yaml
dependencies:
  ack: ^1.7.0-beta.4

dev_dependencies:
  ack_generator: ^1.7.0-beta.4
  build_runner: ^2.4.0
```

The generator works in both directions with one annotation, `@Schemable()`,
from `package:ack/ack.dart`. Constraint annotations such as `@MinLength()` come
from `package:ack/annotations.dart`. `@Schemable()` on a top-level schema generates an
immutable model. `@Schemable()` on a hand-written class generates a public
`<ClassName>Schema` facade, a private Ack codec, and JSON helpers.
There is no `@AckSchema()` annotation; `AckSchema` is the runtime schema type.

```dart
import 'package:ack/ack.dart';

part 'user.ack.dart';
part 'user.ack.g.dart';

@Schemable()
final userSchema = Ack.object({
  'name': Ack.string(),
  'email': Ack.string().email(),
});

@Schemable()
final class Account with _$AccountAck {
  const Account({required this.name});
  final String name;

  static final fromJson = AccountSchema.fromJson;
}
```

Run the generator:

```bash
dart run build_runner build
```

See [Model Code Generation](../core-concepts/typesafe-schemas.mdx) for working
tutorials, supported shapes, and guidance on choosing a direction.
