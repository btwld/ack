---
title: Installing Ack
---

Ack is a pure-Dart package with no required build step. Add the core library — and, optionally, the code generator for immutable models.

## Add to your project

Add Ack to your project using the Dart CLI:

```bash
# For Dart projects
dart pub add ack

# For Flutter projects
flutter pub add ack
```

Or add to your `pubspec.yaml` (check [pub.dev](https://pub.dev/packages/ack) for the latest version):

```yaml
dependencies:
  ack: ^1.6.2 # Replace with latest version
```

## Optional code generator

To generate models from Ack schemas or Ack schemas from hand-written models,
add `ack` and the generator package:

```bash
dart pub add ack
dart pub add --dev ack_generator build_runner
```

Or add them to your `pubspec.yaml`:

```yaml
dependencies:
  ack: ^1.6.2 # Replace with latest version

dev_dependencies:
  ack_generator: ^1.6.2 # Replace with latest version
  build_runner: ^2.4.0
```

The generator works in both directions. `@Schemable()` marks a top-level
schema or a hand-written class. It generates an immutable model, or a public
`<ClassName>Schema` facade with a private Ack codec and JSON helpers.
`@AckInfer()` and `@AckModel()` remain deprecated spellings.

```dart
import 'package:ack/ack.dart';

part 'user.ack.dart';
part 'user.ack.g.dart';

@Schemable()
final userSchema = Ack.object({
  'name': Ack.string(),
  'email': Ack.string().email(),
});

@Schemable()
final class Account({required final String name}) with _$AccountAck {
  static final fromJson = AccountSchema.fromJson;
}
```

Run the generator:

```bash
dart run build_runner build
```

See [Model Code Generation](../core-concepts/typesafe-schemas.mdx) for working
tutorials, supported shapes, and guidance on choosing a direction.

## Requirements

- Dart SDK: `>=3.9.0 <4.0.0` for core `ack`
- Dart SDK: `>=3.13.0 <4.0.0` for `ack_generator`, including primary constructors

Existing applications may keep `ack_annotations`; it re-exports the annotation
API for compatibility.
