---
title: Adapter Package Quickstart
---

Use an [existing adapter](./ecosystem-integrations.mdx) when it supports your
target. To write a new one, start with
[Creating Adapter Packages](./creating-schema-converter-packages.mdx), which owns
the implementation guidance and a contract-test example.

- A JSON Schema target can use `schema.toJsonSchema()` directly.
- A non-JSON target translates `schema.toSchemaModel()` and explicitly handles
  unsupported semantics, nested resources, and references.
- Test required keys, nullability, constraints, and codec wire shapes against the
  target's representation.

The full guide also covers workspace membership and coordinated publishing.
